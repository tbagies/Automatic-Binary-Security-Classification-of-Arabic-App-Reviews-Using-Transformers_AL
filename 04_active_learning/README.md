# 04 Active Learning

Ten five-voter unanimous-agreement iterations. For each app/store, the workflow scans reviews in stable source order and stops at the first row where both unanimous candidate classes reach ten, or after 10,000 reviews, whichever occurs first. The expert-validation batch contains up to ten security candidates. Non-security candidates are randomly sampled with a fixed source-specific seed to match the selected security count; if fewer non-security candidates exist, all are retained alongside up to ten security candidates.
